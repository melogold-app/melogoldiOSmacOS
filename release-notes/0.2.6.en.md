- Mac: the "Melogold wants to access key…" password prompt no longer appears after updates. The session is now kept in a file only your user account can read. Updating to this version may show the prompt one last time — enter your password (or click Deny and sign in again).
- Remote: choosing a device only chooses it. While another device is selected, the playback bar, Now Playing, lyrics, keyboard shortcuts and media keys show and control it; the Device window no longer has a second player. Music that was playing here moves to the chosen device from the same spot.
- Search: type an artist's name and they come first as a large card with Play — their page opens in one tap.
- Albums and playlists: Play and Shuffle are glass buttons, like in macOS 26.
- Apple Watch: Now Playing shows what plays on the selected device; Device only chooses it.
