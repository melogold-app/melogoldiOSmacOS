- Mac: every action that used to be a button only now has a keyboard shortcut, and all of them are in the menus:
  - ♡ — ⇧⌘L, Add to Playlist… — ⇧⌘P, Go to Album — ⌥⌘A, Go to Artist — ⇧⌘A;
  - Shuffle — ⌥⌘S, Cycle Repeat Mode — ⌥⌘R, Mute — ⌥⌘↓, Shuffle Favorites — ⇧⌘F, Device… — ⇧⌘D;
  - Library parts — ⌥⌘1…⌥⌘6 (Favorites, Downloads, History, All Tracks, Albums, Artists), Filter List — ⌥⌘F, sidebar — ⌃⌘S;
  - Import from ViTune or ViMusic… — ⇧⌘I, Save Library Copy… — ⇧⌘S.
- Mac: Shuffle moved from ⌃⌘S to ⌥⌘S, as in Music: ⌃⌘S is now the usual Show or Hide Sidebar.
