- Первая версия Melogold для Mac — дальше приложение обновляется само.
- Песни YouTube Music и видео YouTube: поиск, Тренды, Новое, альбомы, исполнители, плейлисты, ссылки YouTube.
- Свой плеер без пауз между треками, кэш музыки, загрузки, очередь, таймер сна, мини-плеер и управление с клавиатуры.
- Библиотека: Избранное, плейлисты, История, «Все треки», импорт из ViTune и ViMusic, копия библиотеки.
- Синхронные тексты с редактором; выбранный текст одинаковый на всех устройствах.
- Синхронизация через сервер Melogold и вход по коду с другого устройства — без пароля.
