# План выпуска Apple-клиента: публичный Mac и редизайн под Liquid Glass

Составлен 2026-09-30 по просьбе пользователя: «дизайн под Liquid Glass и красивым, сейчас как набросок; довести до
релиза максимального; для macOS сделать релиз в репозитории, чтобы каждый мог скачать, с автообновлением». Основа —
аудит того же дня (сборки 4 платформ, 231 тест пакета, UI-тесты, скриншоты всех экранов, сверка с Android).

Работу ведёт основная сессия (оркестратор): она ревьюит, сливает в `main` и выпускает. Слайсы делают помощники,
не больше двух одновременно на все репозитории; каждый — в своей ветке и worktree.

## Решения (приняты, не переспрашивать)

- Mac распространяется DMG из GitHub Releases без Apple Developer ID: подпись — постоянный самоподписанный сертификат
  Melogold (секреты `MACOS_SELF_SIGNED_P12_*`), обновления — Sparkle с ключом EdDSA (`SPARKLE_ED_PRIVATE_KEY`).
  Предупреждение Gatekeeper при первом запуске — допустимо (решение пользователя), README объясняет, почему.
  Постоянный сертификат, а не ad-hoc: у ad-hoc требование подписи — хеш кода, и после каждого обновления связка
  ключей спрашивала бы доступ к токенам.
- Дизайн — HIG и §5 `PROMPT.md` без отступлений: стекло только в слое навигации и управления (панели, кнопки,
  мини-плеер, листы), не под контентом; акцент системный; фон «Сейчас играет» — мягкий статичный оттенок цвета обложки;
  никакого размытого фона обложки, «живых» пятен, масштаба строк текста. Красота — за счёт иерархии, крупных обложек,
  ритма отступов, системных стеклянных кнопок и анимаций смысла, а не декора.
- Подложка текущей строки текста (задание 0012) — фирменная деталь плеера пользователя: делается первой среди
  дизайн-задач, одинаково на iPhone, iPad, Mac и Vision Pro.
- Текущая строка текста — у самого верха области текста, текст в редакторе — целиком, без «…» (задание 0016).
