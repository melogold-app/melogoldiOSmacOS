# Ход работы: Melogold для Apple

Что сделано по срезам `docs/PROMPT.md` §7, как проверено и что осталось. Следующая сессия продолжает отсюда.

## Как проверять

- `scripts/generate-project.sh` — проект из `project.yml` (XcodeGen собирается из `BuildTools/`).
- `swift test --package-path Packages/MelogoldKit` — правила и общие векторы (`spec/`).
- Сборки (одна `xcodebuild` за раз — Mac общий):
  - `xcodebuild -scheme Melogold -destination 'generic/platform=iOS Simulator' build` — iPhone, iPad и встроенные часы;
  - `-destination 'platform=macOS'`, `'generic/platform=visionOS Simulator'`; схема `Melogold Watch` — `'generic/platform=watchOS Simulator'`.
- UI-тесты iPhone: `TEST_RUNNER_MELOGOLD_SHOTS_DIR=<папка> xcodebuild test -scheme Melogold -destination 'platform=iOS Simulator,id=<UDID>'` — нажатия и снимки экрана.
- UI-тесты часов: то же со схемой `Melogold Watch` и `-destination 'platform=watchOS Simulator,id=<UDID>'` (`MelogoldWatchUITests`, общие приёмы — `UITests/UITestSupport.swift`).
- Симуляторы: iPhone 18 Pro `0FAF8790-…`, iPad Pro 13 `AB782A98-…`, Apple Watch Series 12 46 мм `4BC3A3E8-…`, Apple Vision Pro `DC9E9E35-…`.
  Параметры запуска: `-shell.lastTab <раздел>`, `-AppleLanguages "(ru)"`, `-MelogoldOpenURL <ссылка>`.
- Mac: пока экран заблокирован, системный снимок чёрный; отладочная сборка снимает своё окно сама
  (`-MelogoldSnapshotPath <png> -MelogoldSnapshotDelay 12 -MelogoldSnapshotQuit YES`), но боковую панель на стекле
  в такой снимок система не отдаёт. `-MelogoldMute YES` — без звука (Mac общий).
- **Сеть симуляторов:** когда на Mac включён VPN «Happ», у системного резолвера нет серверов и симуляторы не
  разрешают имена («Сервер с указанным именем хоста не удалось найти»), а процессы самого Mac — разрешают.
  Обход только для отладки: CONNECT-прокси на Mac (`scratchpad/tools/connectproxy.py 8899`) и параметр запуска
  `-MelogoldDebugProxy 127.0.0.1:8899` (UI-тестам — `TEST_RUNNER_MELOGOLD_PROXY=127.0.0.1:8899`).
- Отладочные параметры: `-MelogoldOpen album:<id>|artist:<id>|playlist:<id>|moods|releases` (детальный экран),
  `-MelogoldOpenLink "<ссылка или текст>"` (как вставка в Поиске), `-MelogoldMute YES` (без звука — всегда при проверке
  воспроизведения: симулятор играет через динамики Mac, а рядом спят; после проверки — `xcrun simctl terminate`),
  `-MelogoldSeedLibrary YES` (пример библиотеки из альбома «Группа крови»: лайки, плейлист, история),
  `-MelogoldSeedPlays YES` (два своих прослушивания без сети и без плеера — История и фильтр по устройствам),
  `-MelogoldOpen favorites|history|allTracks|downloads|albums|artists|local:<id>` (экраны библиотеки),
  `-MelogoldSearch "<запрос>"`, `-MelogoldSearchScope music|youtube`, `-MelogoldPlayFirst YES`
  (iPhone, iPad, Mac, часы), `-MelogoldBenchmark "<запрос>" -MelogoldBenchmarkClearCache YES -MelogoldBenchmarkMute YES
  -MelogoldBenchmarkQuit YES` — замер «от нажатия до звука» по 10 трекам в журнал.
- Снимки «Сейчас играет» без нажатий и без гонки со временем (слайс S2): `-MelogoldShowNowPlaying YES -MelogoldShowLyrics YES`,
  `-MelogoldSeedLyrics YES` (свой синхронный текст играющему треку: короткая и длинная строка, подпевка, дуэт с переводом,
  проигрыш 26–34 с) или `editor` (обычный текст с длинной японской строкой для редактора), `-MelogoldSeek <с>
  [-MelogoldSeekPause YES]` (перемотать после старта и встать на паузу), `-MelogoldLyricsEditor marks|words[:N]|second`
  (редактор сразу в «Разметке»; `words` — по словам, N отметок подряд, по умолчанию 4; `second` — курсор на очень длинной строке),
  `-MelogoldShowQueue YES`, `-theme.mode light|dark`, Mac: `-MelogoldWindowSize 720x480`. Всегда с `-MelogoldMute YES`
  и своей папкой `-MelogoldDataDir`. Боком iPhone и iPad снимает UI-тест `NowPlayingUITests` (снимок `XCUIScreen`
  приходит в портретной ориентации — повернуть `sips -r 270`).
- Живые тесты пакета: `MELOGOLD_LIVE=1 swift test --filter "LiveYouTubeTests|LivePlaybackTests"`; синк на настоящем
  сервере — `MELOGOLD_TEST_SERVER=http://127.0.0.1:8787 swift test --filter LiveSyncTests` (без переменной пропускается).
  Локальный сервер для них: `cd melogoldServer && REGISTRATION=open PORT=8787 HOST=127.0.0.1 DATA_DIR=<папка>
  NODE_ENV=development DISK_MIN_FREE_PERCENT=1 node src/main.ts serve` — без `REGISTRATION=open` (по умолчанию `first`)
  сервер регистрирует только первого пользователя, и тесты, которым нужен ещё аккаунт, падают с `registration_closed`;
  `DISK_MIN_FREE_PERCENT=1` — если диск Mac почти заполнен (иначе `503 storage_full`).
- После сборки `git status` чистый: сборка не меняет `*.xcstrings` (числа — `Text(verbatim:)`, `CFBundleDisplayName` и
  `CFBundleName` — в `InfoPlist.xcstrings`); CI это проверяет.
- Сборки и `swift test` — через `/usr/bin/lockf -k <scratchpad>/locks/xcode.lock …`: Mac общий с основной сессией.

### Задание 0008. Кадр видео

Сделано:
- `FrameBars` (MelogoldCore, порт Windows): чёрные поля кадра видео срезаются по пикселям — строка или столбец поле,
  если у 98 % пикселей каждый канал ≤ 28; поля вместе ≥ 3 % стороны, разница сторон ≤ 3 %, остаток ≥ 40 %.
  `FrameCrop.withoutBars` и `centerSquare` на CoreGraphics.
