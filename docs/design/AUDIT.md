# Аудит экранов: Apple (iOS, iPadOS, macOS, watchOS, visionOS)

По `docs/DESIGN-DOCTRINE.md` §4–§5: каждый экран проходит контракты своих элементов; расхождения — задания в `tasks/`.
Строка обновляется в том же коммите, что и работа над экраном.

## Mac (2026-10-01, снимки всех экранов в светлой и тёмной теме, отладочный сценарий `-MelogoldScript`)

Общее для всех экранов Mac:
- **Исправлено:** переходы глубже второго экрана не показывались (колонка очереди `.inspector` висела на стеке колонки
  детали) — «альбом не открывается», «после сворачивания показывает список альбомов»; списки контента — системный стиль
  `.inset` вместо `.plain` (строки прилипали к краю окна при скрытой боковой панели, поля экранов не совпадали); ⇧⌘A
  (стандартное «Снять выбор») больше не занято исполнителем — ⇧⌘R; «Свернуть» в «Сейчас играет» — слева за кнопками окна;
  окно Keychain с паролем; закрытие окна завершало приложение; часы предлагались целью пульта.
- **Решено:** панель воспроизведения — плавающая капсула внизу по центру, как в «Музыке» macOS 26+ (исключение в реестре).
- **Открыто:** крупный шрифт на Mac (Dynamic Type нет,
  HIG просит увеличение ≥ 200 %) — решение проекта; контракты клавиатуры и VoiceOver по экранам ещё не пройдены вручную.
