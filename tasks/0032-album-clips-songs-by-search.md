## Как сделать

1. Сначала, как в 0029, — плейлист альбома.
2. Каждый клип, оставшийся без пары, — поиск YouTube Music «Песни» (params фильтра Songs) по
   `"{исполнители строки} {название}"`, до 8 запросов сразу, итог — в порядке строк.
3. Пара строгая: тип песня (`MUSIC_VIDEO_TYPE_ATV`); то же название без учёта регистра и лишних пробелов; хоть один общий
   исполнитель (по browseId или имени без учёта регистра); длительность песни — длительность строки альбома ±2 с; у строки
   нет длительности — пары нет; один videoId дважды не берётся. Без пары строка остаётся клипом.
4. Замена — videoId и тип; альбом, название и длительность строки остаются.
5. Починка медиатеки (если будет, как Linux 0030) получает ошибку, только если клип остался без пары из-за ошибки
   поиска: ошибку плейлиста сменяет итог поиска.
