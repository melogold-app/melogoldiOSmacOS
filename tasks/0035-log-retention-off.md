# Журнал: срок хранения и выключение (на Маке)

Статус: открыто. На Linux (0036, 0037), Windows (0039, 0040) и Android (0035, 0036) сделано 31.10.2026.

Максим (31.10.2026): «чтобы можно было выбрать, сколько долго хранятся логи, и выключить логирование совсем — на всех
платформах». Его выбор: сроки «День · 3 дня · Неделя · Месяц», при выключении записанное удалить сразу.

## Сделать — так же, как у остальных клиентов

1. «Диагностика»: переключатель «Журнал» / «Log», подпись «Записывать работу приложения в файлы — пригодится, если
   что-то сломается» / «Write what the app does to files — useful if something breaks», по умолчанию включён. Выбор
   «Хранить» / «Keep»: «День», «3 дня», «Неделя», «Месяц» / «A day», «3 days», «A week», «A month» (1, 3, 7, 30 дней),
   по умолчанию неделя. Выключен — «Хранить», «Показать в Finder» и «Экспорт отчёта» в части журнала недоступны.
   Только это устройство, не синхронизировать.
2. `Packages/MelogoldKit/Sources/MelogoldCore/Support/Log.swift`: вместо `melogold.log` / `melogold.previous.log` — файл
   на запуск `melogold-ГГГГММДД-ЧЧММСС.log` (местное время начала файла), новый — после 2 МБ или со сменой даты.
   Падение, если пишется, — `last-crash.txt`.
3. Уборка — при `configure`, с каждым новым файлом и при смене срока: `*.log` и `last-crash.txt` старше срока (по
   времени изменения) удалить; затем, если папка больше 50 МБ, удалять самые старые. Файл, в который идёт запись, не
   трогать. Старые `melogold.log` и `melogold.previous.log` — тоже `*.log`, уйдут по сроку.
4. Выключили — запись в файл встаёт сразу (`os.log` — системный, его оставить), папка журнала пустеет сразу, включая файл
   этого запуска. Включили — сразу новый файл, без перезапуска.
5. «Экспорт отчёта»: журнал в архиве — один `melogold-log.txt` в формате остальных клиентов: шапка (версия, система,
   устройство, время, строка `Журнал: хранить N дн.`), затем `\n===== Падение (last-crash.txt) =====\n`, если есть,
   затем все `*.log` от старых к новым по времени изменения, каждый под `\n===== melogold-20261031-134500.log =====\n`.
6. Тесты (`swift test`): уборка по сроку и по 50 МБ, пишущийся файл не удаляется, выключение очищает папку, порядок
   разделов. Выпуск — со следующим.

Образцы: Linux `crates/melogold-gtk/src/logging.rs` (задание 0037 в `melogoldLinux`), Windows
`src/Melogold.Core/Domain/LogFiles.cs` и `LogReport.cs` (задание 0040).
