# Своё название, исполнитель и альбом трека

Статус: открыто — ждёт сервер (`melogoldServer/tasks/0001-track-overrides.md`: контракт ещё не утверждён)

Общая часть (что нужно пользователю, как должно быть, синк, тексты) — `melogoldWindows/tasks/0011-track-overrides.md`.
Те же задания: `melogoldAndroid/tasks/0012-track-overrides.md`, `melogoldLinux/tasks/0005-track-overrides.md`.

Коротко: собранный из разрозненных видео YouTube альбом (обход цензуры) должен выглядеть одним альбомом на всех
устройствах. Решение пользователя (2026-09-26): на сервере только текст — название, исполнитель, альбом; обложки и
файлы не храним.

## Apple

- `MelogoldData`: миграция GRDB — таблица правок (`video_id` PK, `title`, `artists_text`, `album_title`, `updated_at`);
  правка применяется в одном месте при показе трека (строки, плеер, Now Playing / `MPNowPlayingInfoCenter`, часы,
  «Сохранить файлом»).
- `TrackMenu` → «Изменить сведения…» (sheet на iPhone, окно на Mac); выделенное (`0013`) → «Указать альбом…».
- Поиск текста: LrcLib сначала по правленым названию и исполнителю.
- `LibrarySync`: op `track.override.set` и разбор `overrides`, только если вид есть в `features.sync.kinds`.

## Проверка

Юнит-тесты применения правки и op; живой сервер (временный аккаунт): правка с Windows видна на iPhone/Mac и обратно;
снимки окна «Сведения о треке» и плейлиста-альбома.
