# Задания

Всё, что нужно сделать в этом клиенте, лежит здесь: одно задание — один файл `NNNN-название.md`. В задании описано, что нужно пользователю, решение, контракт и проверка. Задания пишет пользователь или сессия, которая ведёт сервер и Android. Задания для других клиентов лежат в `melogoldAndroid/tasks/` и `melogoldWindows/tasks/`, чтобы клиенты вели себя одинаково.

## Как работать

1. В начале каждой сессии прочитай `docs/PROMPT.md` (основа клиента) и этот файл.
2. Выполняй открытые задания по номерам, сразу, без отдельной команды пользователя. Каждое задание — срез: сборка и тесты → запуск на симуляторе → скриншоты → коммит → push.
3. Задание с номером среза входит в этот срез `docs/PROMPT.md` §7 и делается вместе с ним. Пока клиента нет, начинай со среза 1 и иди по срезам. Задания без среза — сразу, по номерам.
4. Берёшь задание — поставь статус «в работе» в первом коммите работы. Сделал — «сделано», в том же коммите, что и работа. Коммит видно в `git log`: `git log -1 --format=%h -- tasks/NNNN-*.md`.
5. Если в задании что-то не решено или противоречит коду, спроси пользователя, прежде чем делать. Контракт сервера не меняй сам.

Статусы: `открыто` · `в работе` · `сделано`.
