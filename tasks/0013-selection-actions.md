# Действия с выделенными треками: скачать, в Избранное, собрать плейлист

Статус: открыто

Те же задания: `melogoldAndroid/tasks/0011-selection-actions.md`, `melogoldLinux/tasks/0004-selection-actions.md`.
Образец — Windows (сделано, Windows 0.1.10: `Controls/SelectionBar.cs`, `Services/TrackActions.cs`).

## 1. Что нужно пользователю

«Нужно сделать массовые действия: выделить все или конкретные элементы и скачать их, добавить в Избранное или создать
с ними плейлист». И зачем: Melogold — обход ограничений и цензуры в музыке. Альбом, который сначала зацензурировали, а
потом удалили, лежит на YouTube разными видео от разных людей, с разными обложками, а не одним альбомом. Пользователь
находит эти треки поштучно и собирает из них альбом-плейлист.

Сейчас на Mac список уже умеет выделять несколько строк (`SelectableList`, `List(selection:)`), но меню
(`RowActions`, `TrackMenu.swift:172`) показывается только при одном выделенном — для нескольких оно пустое.

## 2. Решение (одинаково на всех клиентах)

- **Выделение** в любом списке треков (Избранное, «Все треки», история, плейлист, альбом, поиск, «Скачанное»):
  - iPhone, iPad, Vision Pro — кнопка «Выбрать» в панели (как в «Фото» и «Музыке»): `EditMode` с отметками; «Готово»
    выходит;
  - Mac — как везде в macOS: ⌘-щелчок, ⇧-щелчок, ⌘A, Esc снимает выделение.
- **Действия** (на Mac — от двух выделенных, панель внизу и правый щелчок; на iPhone — нижняя панель в режиме
  выделения):

  | Действие | Русский | English | Что делает |
  |---|---|---|---|
  | счётчик | Выбрано: {0} | {0} selected | — |
  | ▶ | Слушать | Play | выделенные **в порядке списка** — новой очередью |
  | очередь | В конец очереди | Add to queue | в конец очереди; «В конец очереди: N треков» |
  | ♡ | В Избранное | Add to Favorites | всем сразу, одной записью; «В Избранное: N треков» |
  | + | Добавить в плейлист… | Add to playlist… | обычный выбор плейлиста |
  | новый | Новый плейлист… | New playlist… | диалог названия; **по умолчанию — название альбома**, если у всех выделенных он один; «Плейлист «X»: N треков · Открыть» |
  | ↓ | Скачать | Download | скачанные, скачивающиеся и трансляции пропускаются; «Скачивается: N треков» или «Выделенное уже скачано» |
  | | Выбрать все | Select all | все треки списка |
  | | Снять выделение | Clear selection | — |

- Числа — с формами множественного числа (String Catalog, `%lld`).

Дальше (отдельно, ждёт решения по серверу): у трека в плейлисте можно будет поменять название, альбом и обложку, чтобы
собранный альбом выглядел одним альбомом на всех устройствах.

## 3. Apple

- `RowActions` (`TrackMenu.swift`): при `ids.count > 1` — меню действий с выделенным (те же пункты), треки — через
  `target` в порядке списка.
- Общая панель — `.safeAreaInset(edge: .bottom)` у `SelectableList`, пока выделено ≥ 2 (Mac) или включён режим
  выделения (iOS); на iOS `SelectableList` получает `List(selection:)` в режиме `EditMode.active`.
- ♡ всем сразу — одна транзакция `SyncStore` и одна отправка в синк.

## 4. Проверка

- Юнит-тесты: название по умолчанию (общий альбом / разные / без альбома); «Скачать» пропускает скачанные и
  трансляции; порядок «Слушать» — порядок списка.
- Скриншоты: Mac — три выделенные строки и панель; iPhone — режим выделения и диалог «Новый плейлист».
